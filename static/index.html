YOUR DATA, YOUR DEVICE

A simple privacy promise

CyberGuard analyzes the item you submit to generate a report. It does not store the original message, link, file, or code in an app database.

For your history, this browser saves only a short report locally. Optional text and code explanations send sanitized finding labels—not source content—to the configured provider. If you turn on Gemini visual observations, the selected image is sent to Google Gemini; this option is off by default.

iAvoid submitting secrets, credentials, private files, or personal data. This is a hackathon prototype, not a secure incident-response service.
